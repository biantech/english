# BECGJLX 词汇学习资料

![BEC 词汇精选封面](./cover.jpg)

本目录包含 30 天的 BEC 词汇学习音频，以及与音频同步的英文和中文 LRC 字幕。每个 `DayXX` 文件组相互配套：

- `DayXX.mp3`：第 XX 天的音频。
- `DayXX.lrc`：英文字幕。
- `DayXX_zh.lrc`：带中文翻译的字幕。

将 MP3 与对应的 LRC 文件放在同一目录中，并使用支持 LRC 的播放器播放，即可同步查看字幕。中文字幕文件使用 `_zh.lrc` 后缀，便于与英文字幕区分。

## 使用说明

1. 选择一个 `DayXX.mp3` 音频文件播放。
2. 在播放器中加载同名的 `DayXX.lrc`，查看英文字幕。
3. 需要中文翻译时，改为加载同名的 `DayXX_zh.lrc`。

`cover.jpg` 为本资料封面。文件名中的 `XX` 使用两位数字表示学习天数，例如 `Day01` 和 `Day30`。
